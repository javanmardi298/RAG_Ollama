# Erstattungen

Erstattungen erfolgen immer auf die **ursprüngliche Zahlungsart**. Wir erstatten den Betrag innerhalb von **14 Tagen**, nachdem der zurückgesendete Artikel in unserem Lager eingegangen ist.

Erstattungen bis **150 EUR** werden automatisch genehmigt. Höhere Beträge prüft ein Mitglied unseres Support-Teams; das kann bis zu zwei Werktage länger dauern.

Den Stand einer Erstattung können Sie jederzeit mit Ihrer Bestellnummer erfragen.
