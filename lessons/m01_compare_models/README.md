## چرا این درس
«کدام مدل برای کار من بهتر است؟» یک پرسش اندازه‌گیری است، نه سلیقه. این درس یک **آزمون کوچک و قابل‌تکرار** می‌سازد که روی هر ارائه‌دهنده‌ای (مدل محلی، API ابری، مدل‌های OpenCode) اجرا می‌شود و سه چیز را کنار هم می‌گذارد: **دقت، تأخیر و (برای ابری) هزینه‌ی تخمینی**. این مهارت مستقیماً در رزومه و مصاحبه به‌کار می‌آید.
