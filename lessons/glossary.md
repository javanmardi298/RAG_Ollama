# واژه‌نامه (فارسی ↔ English)

| English | فارسی / توضیح کوتاه |
|---|---|
| chunk | تکه‌ی سند که جست‌وجو و مدل با آن کار می‌کنند |
| retrieval | بازیابی: پیدا کردن تکه‌های مرتبط |
| BM25 | الگوریتم کلاسیک جست‌وجوی کلیدواژه‌ای (tf، idf، نرمال‌سازی طول) |
| embedding | بردار عددی که معنای متن/تصویر را نشان می‌دهد |
| hybrid search | ترکیب دو جست‌وجو (مثلاً BM25 + embedding) |
| RRF | Reciprocal Rank Fusion؛ ترکیب فهرست‌ها با رتبه، نه امتیاز |
| recall@k | آیا سند درست در k نتیجه‌ی اول هست؟ |
| MRR | میانگین عکس رتبه‌ی اولین سند درست |
| RAG | تولید جواب با کمک بازیابی از منابع |
| Agentic RAG | RAG با حلقه‌ی تصمیم: مسیریابی، نمره‌دهی، بازنویسی، راستی‌آزمایی، امتناع |
| grading | نمره‌دادن به تکه‌ها (مرتبط/نامرتبط) |
| abstain | امتناع؛ «نمی‌دانم» گفتن وقتی شاهد کافی نیست |
| hallucination | ساختن واقعیت توسط مدل |
| citation | ارجاع به منبع |
| verify | راستی‌آزمایی پاسخ نسبت به شواهد |
| provider | ارائه‌دهنده‌ی مدل (Ollama، Anthropic، OpenCode، …) |
| latency | تأخیر؛ زمان پاسخ |
| budget | سقف هزینه |
| pass^k | احتمال موفقیت در همه‌ی k اجرا (پایایی) |
| seed | بذر تصادفی؛ برای تکرارپذیری |
| baseline | نقطه‌ی مقایسه‌ی ساده |
| leakage | نشت؛ استفاده‌ی ناخواسته از داده‌ی آزمون در تصمیم‌ها |
| JEPA | Joint-Embedding Predictive Architecture؛ پیش‌بینی در فضای embedding |
| patch | تکه‌ی کوچک تصویر |
| mask | ماسک؛ پنهان کردن بخشی از ورودی |
| EMA | میانگین متحرک نمایی |
| collapse | فروپاشی نمایش؛ همه‌ی ورودی‌ها یک embedding می‌گیرند |
| effective rank | رتبه‌ی مؤثر؛ تعداد جهت‌های واقعاً استفاده‌شده |
| linear probe | طبقه‌بند خطی روی encoder منجمد برای ارزیابی |
| world model | مدلی که نتیجه‌ی عمل را پیش‌بینی می‌کند |
| CEM / MPC | روش برنامه‌ریزی نمونه‌محور / کنترل پیش‌بین |
| MCP | Model Context Protocol؛ اتصال ابزار به مدل |
| teacher mode | حالت معلم؛ راهنمایی بدون دادن جواب |
